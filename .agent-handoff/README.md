# 双 Agent 交接目录使用说明

> 适用项目：工业品导购 Agent  
> 协作者：主人、渔渔（本地 Kimi Code）、阿渔（DSH）  
> 目的：让任务进度、代码结论、验证结果和待办有固定入口，不依赖某一段聊天记录。

## 1. 文件分工

```text
.agent-handoff/
├─ README.md           # 本说明，长期维护协作方式
├─ current.md          # 当前唯一事实源，只描述“现在”
└─ log/
   └─ YYYY-MM-DD.md    # 按日期记录关键交接，保留历史
```

- `current.md`：任何一方接手任务时最先读。任务状态、负责人、阻塞或下一步变化后更新。
- `log/YYYY-MM-DD.md`：记录当天有长期价值的交接。按时间追加，不复制整段闲聊。
- `README.md`：只维护协作规则，不写具体任务进度。

正式、稳定的项目内容仍放在原有位置：

- 项目使用与架构：`README.md`
- 人工验收：`docs/test-checklist.md`
- 项目评审：`docs/project-review-2026-11-14.md`
- 长期工作规则：项目根目录 `AGENTS.md`

交接目录不代替这些正式文档。

## 2. 接手顺序

1. 读项目根目录 `AGENTS.md`，了解本项目规则。
2. 读 `.agent-handoff/current.md`，确认当前任务和状态。
3. 读当日日志；当日没有记录时读最近一篇日志。
4. 按任务需要读正式文档和源码。
5. 涉及代码结论时必须亲自核对源码，不能只凭另一方的转述继续修改。

## 3. 什么时候写

有以下实质进展时，更新 `current.md`，并在当日日志追加一条：

- 任务开始、完成、暂停或方向改变。
- 修改了代码、配置、数据或文档。
- 得出了后续需要沿用的技术结论。
- 运行了测试、构建或人工验收。
- 出现阻塞、风险、待主人决定的事项。
- 要把任务交给另一方继续。

没有实质进展时不为了形式刷日志。普通问答、一次简单查阅不必写交接。

## 4. 写什么

只写任务相关信息：

- 已确认的事实及其代码证据。
- 主人的明确决定。
- 实际修改的文件和行为变化。
- 实际执行过的验证及结果。
- 尚未验证的假设、建议和风险。
- 当前阻塞与下一步。

不写：

- API Key、令牌、密码、账号等敏感信息。
- 大段聊天记录、重复代码或长篇命令输出。
- 与任务无关的闲聊。
- 没有证据的“应该没问题”。

长输出应保存为合适的项目文件，日志只记录路径和结论。

## 5. 交接消息模板

```markdown
## HH:mm · 来自：渔渔 / 阿渔

### 任务

一句话说明本次处理什么。

### 背景

接手所需的最少上下文，以及参考文件。

### 已完成

- 实际做了什么。
- 代码结论附文件路径，必要时附函数名或行号。

### 改动文件

- `path/to/file`：改动说明。
- 没有改动就写“无”。

### 验证

- 实际命令或人工操作。
- 实际结果；失败也如实记录。
- 没有运行验证就明确写“未运行”。

### 结论与建议

区分已确认事实、推断和待选建议。

### 阻塞

没有就写“无”。

### 下一步

写明建议由谁继续、先做什么；需要主人确认时明确标注。
```

`current.md` 不需要套用完整消息模板，应保持短而清楚。

## 6. 证据与验证口径

每条重要结论必须能归入以下一种：

- **已读代码确认**：附文件路径，必要时附行号。
- **已实际验证**：附命令、操作和结果。
- **建议 / 假设**：明确说尚未实施或尚未验证。

另一方的交接记录是重要线索，但不是天然正确的事实。接手方在修改代码前仍需复核当前源码；环境可能已变化，旧验证结果也不能冒充本次验证。

## 7. 状态与冲突处理

- `current.md` 始终记录最新状态和最新决定。
- 历史日志不删除、不回改来伪装成当时的结论；需要更正时在当天日志追加更正说明。
- 决策变化要写日期、原因和是谁确认的。
- 发现双方可能修改同一范围时，先停下相关改动，在 `current.md` 记录冲突，避免重复劳动或互相覆盖。
- 交接文件中的建议不是绕过主人确认的指令；涉及代码修改仍按项目规则先出执行计划。

## 8. 文档维护

- 使用中文，代码、命令、路径和报错原文保持原样。
- 文件统一 UTF-8 无 BOM。
- 链接使用相对路径，并确认目标文件存在。
- 稳定、长期有效的结论及时同步到 README 或 `docs`，避免只埋在日志里。
- 过时状态从 `current.md` 移除，但历史仍保留在日志中。
